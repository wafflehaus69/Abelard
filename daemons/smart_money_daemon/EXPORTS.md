# EXPORTS - every CSV the smart_money dashboard serves

Base `http://100.106.84.115:8787` (Tailscale only, GET only). Source: `dashboard.py` at 56e904f. Fact-checked at c3b7dbb; the one change since is the `unmapped` column on the buy-cluster export.
Row counts are from the mirror with `anchor=2026-10-01`, run through the production builders. Two inputs are local files, not part of the mirror: overlay tickers (the scoped counts) come from the dev checkout's `config/overlay.yaml`, and seeds and 13F filers from `analysis/registry.json` in the WSL state home (as_of 2026-07-31; its 28 filers are exactly the 28 CIKs in the mirror's 13F table). Production's copies of both were not read.
Live fetch by the author, 2026-10-01 19:18 ET, not repeated in the fact-check: 15 of the 16 forms below returned 200 with the header row the code defines and page-1 byte counts equal to the mirror's; `/clusters.csv` (buy) returned 500. That was fixed the same evening at 56e904f and re-fetched at 21:19 ET: 200, 100 rows paged, 354 with `full=1`.

**Shared parameters**

| Param | Meaning | Default | Allowed |
|---|---|---|---|
| `full` | whole dataset: skips pagination and nothing else (all endpoints) | off | exactly `1` (`true` is ignored) |
| `per_page`, `page` | page size, page number (all endpoints) | 100, 1 | 25, 50, 100, 250, 500; page >= 1 |
| `sort`, `dir` | row order only, never contents (all endpoints) | per endpoint, `desc` | a row key; `asc`, `desc`. Trades sorts only on person, ticker, side, trade_date, reported_date, value, shares, exec_price. An unknown key is not rejected, see 9 |
| `anchor` | "today" for date windows (trades, sentinels, clusters, flows; ignored elsewhere) | server's today | `YYYY-MM-DD`; a string that is not a date is HTTP 500 |
| `window` | days back from anchor (trades, sentinels, sell clusters) | 90 | integer, clamped to 1..3650 |

**Things to know**

1. **OGE carries a statutory use restriction.** The code and schema record that Form 278e reports fall under the Ethics in Government Act, 5 U.S.C. app. 105(c): no commercial use (news media excepted), no credit rating, no solicitation, civil penalty up to $11,000. Every row carries `use_restriction` = `NOT TO BE USED FOR COMMERCIAL PURPOSES` (362 of 362, column is NOT NULL) and the file downloads as `oge_278e_RESTRICTED`. The tag is provenance, not permission. The pipeline keeps this table out of the scan and alert path; the code treats every other source here as unrestricted.
2. **`full=1` lifts pagination only.** `/trades.csv?full=1` is buys, overlay tickers, last 90 days: 7 rows. The widest form is `/trades.csv?full=1&side=all&scope=all&window=3650`: 141,619 of the table's 150,373 P/S rows. Out of reach by any parameter: 8,745 rows collapsed by the amendment dedup, 7 trades dated before 2016-10-03 (the 3650-day clamp), 2 rows with `date_flag` set, and all 201,146 non-P/S rows.
3. **`/clusters.csv?which=buy` answered HTTP 500 from 2026-09-22 to 2026-10-01.** Every buy row carried an `unmapped` key the column list did not name, so the export's completeness check raised. Fixed at 56e904f: `unmapped` is now the last column. `which=buy` is the default, and it is what the buy table's own CSV link requests.
4. **An error is an HTML page with status 500**, not a CSV. A non-date `anchor` does it on trades, flows, sentinels and clusters. Check the status before saving.
5. **A wrong selector falls back without saying so.** `filer=999` returns Duquesne; an unknown `period` returns the newest; an unknown `member` returns the first alphabetically (on OGE, the only filer); `myear=1999` returns that member's newest year. Only `cmte` and `cticker` return a header and no rows. Filenames do not settle it: member, oge, disagreements and committees files never name the subject, and portfolio and insider_book files echo the request (`filer=999` saves as `portfolio_999_latest_...` and holds Duquesne). Check the contents.
6. **Do not page to the end.** A page past the last returns the last page again (`page=999999` gave page 260 of 260). Use `full=1`.
7. **Trades dollars need filtering before any sum.** In the widest export `value_flag` is set on 244 rows and `value` is blank on every one; 328 more blanks have no flag (no price filed). `value_quality` marks 324 rows (110 buys, 214 sells) that hold 49.4% of buy dollars ($31.2bn of $63.2bn) and 15.0% of sell dollars. Also present, marked not removed: 4,176 co-filed rows and 3,127 fund-issuer rows. `ticker` is `-` on 1,222 rows where no symbol was filed; do not group on it. `date_is_reported` is `False` on all 141,619 rows. There is no `date_subclass` column: 271 P/S rows in the table are marked non_trading_day and the CSV does not show which.
8. **`value_quality` depends on which rows are in the export.** One of its tests compares a price with the median price for the same ticker among the rows the filters returned. The same 25,965 trades carry 27 marks in the 90-day export and 70 in the 3650-day one; 51 trades differ. `value_flag` is stored and does not move.
9. **Flows hides its exclusions, and an unknown sort key is not ignored.** Dollars and shares of 1,817 untrusted rows are set to 0 with no mark (the person still counts); fund issuers and co-filed duplicates are dropped. Sort keys are the row keys `persons_N`, `value_N`, `shares_N`, not the header names. `sort=val_all` returns the same rows ordered by net insiders instead of net dollars (first row TSM, not RSG), so page 1 differs; `sort=value_all` works. Any unknown key does the same on portfolios, member and disagreements (query order replaces the default order). The other exports keep their default order.
10. **Sentinels.** `window` is multiplied by 4 and sets only a floor, anchor minus 4 x window; nothing caps the top: `anchor=2025-01-01&window=90` returns 15,787 rows running to 2026-09-02. 13F rows are single holding lines with `value` already in dollars: do not multiply by `value_scale` again (808 rows show 1000). `owner` is the raw filing code (JT, Joint, SP, Spouse, Self, Child, DC), unlike the other congress exports. For 860 of 4,043 congress rows `ticker` holds the first 40 characters of the asset name because no symbol was filed. `date_note` is set on 10 congress rows, 4 of them with `lag_days` blanked. There is no `value_flag` column; no seed's Form 4 row carries one today.
11. **Portfolio `value` is dollars**: it equals the sum of `value_usd` for all 28 filers' newest period, and the scale agrees with the stored `value_scale` in 225 of 225 filer-periods. `exited` rows are synthetic (value 0, shares 0, dates of the prior filing), 23 of Duquesne's 118 and 306 of the 2,008. The on-screen unit warning is not in the CSV (1 filer: Founders Fund VII, $2.0M book).
12. **`/congress.csv` `yoy_change` is a raw count difference** between the last two filing years a ticker appears in, counted on roster-confirmed members. For 190 of the 1,872 rows the later year is 2026, which has 10 confirmed filers against 506 for 2025 (112 against 639 before the roster filter). It is negative on 357 rows, 169 of them among those 190 (AAPL -76 is 3 holders against 79). For change, use `delta_comparable` in `/breadth_yoy.csv`.
13. **The CSV links on a committee page drop `cmte`** and export the committee roll instead. Type the URL.
14. **Cell formats.** `symbol_twins`, `confidence_why` and `asset_types` are Python reprs (`['JT']`, `{'ST': 45}`), not JSON. An empty `value_hi` beside a filled `value_lo` is an open top band. Filenames end in the server's local time, `name MM.DD.YY HH.MM.csv`.
15. **Live results move daily.** `anchor` defaults to the server's date, and `latest_close` is the ticker's newest stored close (prices run to 2026-09-30 on the mirror) whatever the anchor. Pass `anchor` to pin a window.
16. **Rows do not carry their subject or a join key.** `/portfolios.csv` has no filer column; `/member.csv`, `/insiders.csv` and `/oge.csv` have no member or filer column. Add one before stacking files. `/trades.csv` has no accession or CIK and `/flows.csv` has ticker only, so neither joins back to the tables exactly; query the mirror for that.
17. **Stale comment.** `dashboard.py` says `value_flag` is on 293 of 321,991 rows. The mirror has 553 of 351,519, of which 261 are P/S rows.
18. **`owner` = `self` is also the fallback** in member, insiders and the `cticker` export. 1,546 of 146,093 annual-FD rows hold unparsed owner text and read `self`. `/member.csv` also files PTR flows whose owner is written Joint, Spouse, Child or sP under `self`: 316 of the 5,179 PTR rows that enter member flows, 13 members (all 77 of Mullin's flow rows read `self`; his PTRs are 122 Joint, 30 Spouse, 30 Self).
19. **`/disagreements.csv` leaves rows out and says nothing.** 163 13F holding lines with no mapped ticker ($59.4bn, counted across both compared periods) are not compared, and for 2 filers positions under 0.25% of book express no direction.
