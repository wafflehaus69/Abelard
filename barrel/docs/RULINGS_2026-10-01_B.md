## Rulings

1. Post-BOOST day run: authorized, ≤ 250 credits. It's the last unmeasured cost driver (post-BOOST days run ~3× the rows), the credits expire on the 6th, and it replaces a ×1.5 guess with a number. One-day scope, new-pattern rules apply.
2. Column 86 (`seta_lat_s`): seconds from a set member's first SOL inflow from its classified funder to its first acquisition of the token; per token, the median across set members; NULL when the funder is unknown.
3. Count columns: raw and collapsed side by side, every one of them. Collapsed is the value the hypotheses use; raw stays for diagnosis and for the day someone asks why a number changed.
4. Fan-out threshold: no single number, because fan-out alone doesn't classify on Solana. Half the labelled exchanges paid ≤ 15 recipients, and ~15,000 unlabelled senders paid > 1,000. Ruling is a label-first classifier: labelled exchange → exchange regardless of fan-out; unlabelled with fan-out ≥ 400 → hub, never links; unlabelled below 400 → purpose-built, links. 400 is provisional; 32 and 8,192 are reported as sensitivity on the calibration slice and v1.2 freezes it. One addition, pre-registered now: a "factory" class — unlabelled, high fan-out, whose recipients' first actions concentrate on the same tokens within 24h. The 1,128-wallet funder from the readiness run is exactly this and the hub rule would exclude it. Factories link. ClaudeCode measures recipient token-overlap for unlabelled high-fan-out senders on the week; if the two populations separate, the class ships in v1.2.
5. Launch-day fallback block: rejected. Nine blocks for a week destroys power and tells us nothing. Fallback is the creator wallet itself — each unlinked creator is its own block. Report the block count under that rule.
6. Aligned-set definition: the corrected version (wallets that held the token) stands; the readiness figure is struck. A median set size of 1 is the honest number and it's fine — RUG-A is about what that one wallet does.
